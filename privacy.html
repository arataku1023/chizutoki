プライバシーポリシー

最終更新日：2026年10月17日

「ちずとき uploader」（以下「本ツール」）は、YouTube チャンネル「ちずとき」の運営者が、自分のチャンネルを運営するためだけに使う内部ツールです。一般の方には提供していません。

1. 使う Google のデータ

本ツールは、運営者が Google の認可画面で許可した範囲で、YouTube Data API と YouTube Analytics API を通じて、運営者自身のチャンネルの次のデータを扱います。

  • 動画のアップロード、タイトル・説明・公開設定・予約時刻・サムネイル・再生リストの設定
  • 運営者のチャンネルの動画の公開状態と、そこに付いたコメントの取得
  • 運営者のチャンネルの再生回数・視聴時間などの分析データの取得

運営者以外のユーザーのアカウントに対して認可を求めることはなく、他のチャンネルのデータを集めることもありません。

2. 保存と共有

  • 認可の情報（トークン）と取得したデータは、運営者のパソコンの中にだけ保存します。
  • 取得したデータを第三者に販売・提供・共有することはありません。広告や、本ツールの目的以外には使いません。
  • 本ツールによる Google API から受け取った情報の使用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。

3. 許可の取り消し

本ツールへの許可は、Google アカウントの「サードパーティのアプリとサービス」からいつでも取り消せます。取り消すと、本ツールは YouTube のデータにアクセスできなくなります。

4. YouTube の規約

本ツールは YouTube API サービスを使っています。YouTube の利用規約と、Google のプライバシーポリシーもあわせてご確認ください。

5. 変更とお問い合わせ

内容を変えるときは、このページを更新します。お問い合わせは、このページのリポジトリの Issues からお願いします。

Privacy Policy (summary in English)

"chizutoki uploader" is used only by the owner of the YouTube channel "chizutoki". With the owner's authorization, it uses the YouTube Data API and YouTube Analytics API to upload and schedule videos, set thumbnails and playlists, and read comments and analytics for the owner's own channel only. Tokens and data are stored only on the owner's computer and are never sold, shared, or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at https://myaccount.google.com/permissions. This tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
